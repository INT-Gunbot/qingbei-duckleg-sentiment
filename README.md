# 清北鸭腿事件 · 舆情分析项目

> 「鹅腿阿姨」以鸭充鹅事件全链路舆情分析：传播概况 → 群体画像 → 话题分析 → 情感与数据分析，
> 方法链：jieba 分词 → LDA 主题提取 → SnowNLP+情感词典 → TextRank 摘要 → ECharts 可视化。

## 事件背景（真实，2026.06）

- **06-09 20:15** 走红于清华/北大/人大的摊主陈秀凤在国贸团购群公告承认「原材料是鸭腿」，截图扩散
- **06-10** #鹅腿阿姨卖的是鸭腿# 登顶热搜；发绿肉质、其子「不吃滚出去」言论曝光，北大删除背书推文
- **06-11** 海淀区市监局发布情况通报，中消协关注，法学生拟集体诉讼
- **06-14** 全网累计监测 **21 万+ 条**信息，微博占比约 **65.9%**，7 个话题登顶热搜 TOP1

## 目录结构

```
qingbei-duckleg-sentiment/
├── data/                  # 语料（raw_comments.csv 约 2200 条样本）
├── src/
│   ├── spider_weibo.py    # 真实微博采集脚本（填 Cookie 即可跑真实数据）
│   ├── generate_corpus.py # 演示语料生成器（半真实：真实事件框架+真实评论引文）
│   ├── analyze.py         # 分析管线：分词/LDA/情感/TextRank/词频 → JSON
│   └── build_report.py    # 渲染 ECharts 暗色报告 report.html
├── output/                # analysis_result.json
└── report.html            # ★ 最终可视化报告（浏览器直接打开）
```

## 复现步骤

```bash
python src/generate_corpus.py   # 生成演示语料（或用 spider_weibo.py 采集真实数据替换）
python src/analyze.py           # LDA + 情感 + 摘要 → output/analysis_result.json
python src/build_report.py      # 生成 report.html
```

依赖：`jieba snownlp pandas numpy scikit-learn`（Python ≥ 3.10）

## 数据说明（重要）

微博搜索接口需登录态，沙箱内无法直接抓取，语料为**半真实构造**：
事件事实、时间线、热搜阅读量、平台占比、总声量均取自真实公开报道（新华社/澎湃/红星/拓尔思网察等）；
语料含 **607 条**媒体报道引用的真实网民评论原话，其余为按真实立场分布生成的演示样本。
接入真实数据仅需运行 `spider_weibo.py`（填 Cookie），下游分析代码零改动。

## 核心结论（摘要）

1. **舆情本质**：情感信任透支引发的「情怀背刺」事件，学生群体的信任反噬放大传播势能
2. **传播机制**：正面人设彻底反转自带冲突性，反差叙事被平台反复推流，倒 U 型走势、双峰结构
3. **议题升级**：欺诈定性 → 食品安全（发绿腿）→ 当事人失格 → 优绩主义/造神反思，四级外溢
4. **管理建议**：食材明示与退一赔三止损 / 网红摊贩长效抽检机制 / 平台克制「造神式」推流
